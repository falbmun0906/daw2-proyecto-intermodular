Componentes Interactivos

Componentes que proporcionan feedback visual y mejoran la experiencia de usuario.

Tooltips

Los tooltips muestran información adicional al hacer hover o focus sobre un elemento.

Hover arriba Hover derecha Hover abajo Hover izquierda

Toasts (Notificaciones globales)

Los toasts son notificaciones temporales que aparecen en la esquina de la pantalla. Se auto-eliminan después de un tiempo configurable.

Toast Success Toast Error Toast Warning Toast Info

Spinner / Loading Global

El spinner overlay se muestra durante operaciones asíncronas para indicar que la aplicación está procesando.

Mostrar Spinner (2s)

Theme Switcher

El toggle de tema está disponible en el header de la aplicación. Permite cambiar entre tema claro y oscuro. La preferencia se persiste en localStorage.

💡 Prueba el switch de tema en el header (esquina superior derecha)
